# fennec

**FENNEC** — premium gaming & computer-hardware ecommerce store built for the Algerian market.

Named after the fennec fox (Algeria's national animal and the nickname of *Les Fennecs*), the store sells GPUs, CPUs, laptops, monitors, and peripherals with cash-on-delivery checkout across all 58 wilayas.

## Stack

- **Next.js 16** (App Router, Turbopack)
- **React 19** + **TypeScript**
- **Tailwind CSS v4**
- **Motion** (Framer Motion) for animations
- **lucide-react** icons

## Features

- Full-bleed animated hero slider with real product imagery
- Product catalogue with category / brand / price / stock filters and sort
- Product detail pages (gallery, specs, related products)
- Command-palette search
- Cart with localStorage persistence and a slide-in drawer
- Interactive PC configurator (live total, compatibility)
- Checkout (`/commande`) with 58-wilaya delivery, stop-desk / home options, and COD payment
- Trilingual **FR / AR / EN** with full **RTL** support

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
